# Новые каналы и инструменты (май-июль 2026)

> Источник: лента новостей Яндекс Рекламы (yandex.ru/adv/news, тег «Директ»),
> подтверждено пользователем. Не критично для аудита, но полезно для
> рекомендаций в `/direct optimize` — расширение охвата за счёт новых каналов.

- **Реклама в мессенджере МАКС** — доступна через Директ в бета-режиме,
  оплата за клики, автоподбор каналов
- **Автоподбор Telegram-каналов** — теперь по описанию бизнеса, без ручного
  подбора площадок
- **Реклама в Алисе** (голосовой ассистент) — стала полноценным рекламным
  каналом: локальные и контекстные подсказки
- **Новый Мастер отчётов** — группировка по регионам, работа с ключевыми
  фразами, новые виды графиков — использовать вместо старой статистики
  при более глубоком отчёте (`/direct report`)
- **Обновлённое мобильное приложение Директа** — расширенная аналитика
  Мастера отчётов, ИИ-помощник, вход через управляющий аккаунт
